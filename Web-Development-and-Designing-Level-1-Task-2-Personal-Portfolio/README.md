
# Personal Portfolio Website

## Project Description
A modern, visually attractive, and responsive personal portfolio website designed to showcase my introduction, technical skills, projects, and contact information as an aspiring web developer.

## Technologies Used
- HTML5
- CSS3
- Google Fonts

## Features
- Responsive navigation bar with smooth scrolling
- Hero section with name, role title, and introduction
- About Me section describing background and interests
- Skills section showcasing technical skills
- Projects section with at least two project cards
- Contact section with email and social media links
- Modern dark theme with purple and blue colour scheme
- Hover effects and CSS animations
- Responsive design for mobile and desktop
- Clean typography and proper spacing

## Project Structure
- `index.html` – Contains the HTML structure.
- `style.css` – Contains the styling and layout.
- `images/` – Stores website images and profile pictures.
- `README.md` – Project documentation.

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in your browser.
3. View and explore the personal portfolio website.

# Landing Page

## Project Description
A visually attractive and responsive landing page designed for a product, service, or brand.

## Technologies Used
- HTML5
- CSS3

## Features
- Fixed or sticky navigation bar
- Hero section with headline and call-to-action button
- At least two content sections
- Footer with contact and social media links
- Consistent colour scheme
- Responsive design for mobile and desktop
- Clean typography and proper spacing

## Project Structure
- `index.html` – Contains the HTML structure.
- `style.css` – Contains the styling and layout.
- `images/` – Stores website images and profile pictures.
- `README.md` – Project documentation.

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in your browser.
3. View and explore the landing page.

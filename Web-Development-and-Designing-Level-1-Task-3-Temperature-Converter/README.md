
# Temperature Converter Website

A responsive and interactive Temperature Converter Website developed as part of the **Oasis Infobyte Web Development & Designing Internship – Level 1, Task 3**.

## Project Overview

The Temperature Converter allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin. It provides instant results, input validation, and a clean, user-friendly interface.

## Features

- Convert temperatures between Celsius, Fahrenheit, and Kelvin.
- Select the input temperature unit.
- Display all three temperature values together.
- Validate numeric input.
- Display error messages for invalid or empty input.
- Prevent temperatures below absolute zero.
- Responsive design for desktop and mobile devices.
- Elegant light-themed user interface.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- Google Fonts (Poppins) – Modern and elegant typography.
- Vanilla JavaScript – Temperature calculations, input validation, and interactive functionality.

## How to Run

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Enter a temperature and select its unit.
5. Click the Convert button to view the results.
